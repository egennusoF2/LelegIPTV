Installazione Android smartphone e tablet

  1. Scarica LelegIPTV-android-universal-release.apk.
  2. Apri Impostazioni > Sicurezza > Installa app sconosciute.
  3. Autorizza il browser o il file manager con cui aprirai l'APK.
  4. Apri l'APK e completa l'installazione.

Se Android segnala una firma diversa, disinstalla una eventuale vecchia LelegIPTV e reinstalla l'APK corrente.

I download locali vengono affidati al Download Manager di Android: dopo il tap su Download compare la notifica di sistema e il file resta accessibile dalla sezione Download dell'app.

Installazione Android TV / Google TV

Metodo ADB

  1. Abilita Opzioni sviluppatore e Debug ADB sulla TV.
  2. Dal computer collegato alla stessa rete esegui:
adb connect IP_DELLA_TV:5555
adb install -r LelegIPTV-android-universal-release.apk

Metodo Downloader / file manager

  1. Copia l'APK su USB o scaricalo con Downloader.
  2. Autorizza Installa app sconosciute per l'app usata.
  3. Installa e avvia LelegIPTV dalla schermata app.

Installazione iOS, iPadOS e macOS

iPhone e iPad con Scarlet, Sideloadly o AltStore

  1. Scarica LelegIPTV-ios-unsigned.ipa.
  2. Metodo Scarlet: apri scarlet-ios.com, installa Scarlet seguendo le istruzioni del sito, poi importa l'IPA scaricata.
  3. Metodo Sideloadly / AltStore: apri lo strumento sul Mac/PC, collega iPhone o iPad via USB e seleziona l'IPA.
  4. Firma con Apple ID personale quando richiesto dallo strumento scelto.
  5. Alla prima apertura autorizza lo sviluppatore da Impostazioni > Generali > VPN e gestione dispositivo.
  6. Con Apple ID gratuito ricarica l'app periodicamente, di solito ogni 7 giorni.

Su iOS/iPadOS i download offline sono salvati nativamente in File > Su iPhone/iPad > Leleg IPTV > LelegIPTV. La cartella e' condivisa dall'app e i contenuti possono essere aperti dalla sezione Download.

macOS

  1. Scarica LelegIPTV-macos-arm64-release.dmg.
  2. Apri il DMG e trascina LelegIPTV.app in /Applications.
  3. Se Gatekeeper blocca l'app non notarizzata, apri Impostazioni di Sistema > Privacy e Sicurezza e scegli Apri comunque.

Alternativa terminale: xattr -dr com.apple.quarantine "/Applications/LelegIPTV.app"

Samsung Tizen TV

La versione Tizen parte dalla app Flutter nativa, non dalla vecchia build web. Il pacchetto pronto e' LelegIPTV-tizen-tv-release.tpk.

Stato tecnico: il TPK e' generato dalla app Flutter e include il backend Samsung AVPlay tramite video_player_avplay. Su Tizen non viene usato media_kit, perche' richiede libmpv e non e' adatto alle TV Samsung.

  1. Abilita Developer Mode sulla TV Samsung e inserisci l'IP del computer.
  2. Collega la TV con Tizen Studio / Device Manager oppure via sdb connect IP_TV:26101.
  3. Installa il TPK dalla CLI:
sdb connect IP_TV:26101
tizen install -n LelegIPTV-tizen-tv-release.tpk -t IP_TV:26101

Se la TV rifiuta la firma, rigenera il certificato Samsung Developer includendo il DUID della TV e ricompila il TPK.
